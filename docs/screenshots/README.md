### CARA MENGAMBIL SCREENSHOT DENGAN MUDAH:

1. **Dari Android / iOS (Expo Go):**
   - Ambil screenshot pada HP Anda (Power + Volume Down).
   - Kirim ke laptop (via WhatsApp Web, Google Drive, atau kabel data).
   - Ubah nama berkas sesuai tabel di atas dan pindahkan ke folder `docs/screenshots/`.

2. **Dari Web Browser (http://localhost:8081):**
   - Buka browser Chrome / Edge.
   - Buka DevTools (`F12`), aktifkan toggle device emulator (`Ctrl + Shift + M`) untuk tampilan rasio ponsel (misal iPhone 14 Pro atau Pixel 7).
   - Gunakan fitur tangkapan layar browser atau Snipping Tool (`Win + Shift + S`) di Windows.
   - Simpan langsung ke folder `docs/screenshots/`.

Setelah seluruh berkas disimpan dengan nama di atas, gambar akan **otomatis muncul** di dalam laporan `LAPORAN_UTS_PBP_GATHAN_HILABI.md` saat dibuka di VS Code Preview (`Ctrl + Shift + V`) maupun saat di-push ke GitHub.
